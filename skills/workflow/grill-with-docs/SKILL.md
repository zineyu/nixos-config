Call the Skill tool twice, for "grilling" and "domain-modeling".

The paper trail from this session is exactly what `domain-modeling` asks for: a resolved term goes into `GLOSSARY.md`, a hard-to-reverse trade-off goes into an ADR under `docs/adr/`, and each one is written at the moment it crystallises. Keep the plan itself in the conversation. A spec document is the output of `/to-spec`, so this session writes no spec file and no other doc.
